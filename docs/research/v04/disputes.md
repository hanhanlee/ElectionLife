# V0.4 第一輪：研究員之間的歧見

> 四位研究員：B 原始資料、C 雙方說法、D 制度與數據、E 反向查核（E 沒看其他人的結論）。
> 下面列出結論不同或互相補充、需要說明的地方；沒有列出的命題，四份報告結論一致。

## D1｜公報頁碼（C09）

- **B**：從公報 Word 版讀到決議全文。位置是第 19 次全體委員會議（2020-12-14）那一冊裡，宣讀確認的「第 18 次會議議事錄」（2020-12-09、10），衛福部項下通過決議第（三十一）項。確切頁碼沒取得。
- **E**：從媒體轉述得到相同內容；但公報目錄上第 133–372 頁是第 19 次會議（口腔健康與罕病法專題報告），目錄沒有預算凍結案，所以認為媒體寫的「第 165 頁」對不上。
- **主 agent 判斷**：兩者不衝突。決議收在第 19 次會議宣讀確認的第 18 次會議議事錄裡，目錄只列第 19 次會議的議程，所以看不到。決議內容兩人一致。
- **仍待人工**：用 PDF 確認頁碼；確認這項凍結決議後來在院會是否維持。

## D2｜「父親是台商」的框架（C11）

- **C**：遊戲句「你說過，父親是在中南美洲做貿易，這則消息一兩年前就有人炒過」和沈伯洋的說法、2025-06 港媒報導都相符，可以照用。
- **E**：國民黨稱父親公司 2008 年以來近 7 成 5 的交易來自中國，陸委會也說是向大陸下單、再出口中南美；各方不否認大量向中國採購，爭點是這算不算「在中國做生意」。遊戲把整件事寫成「舊謠言重炒」，等於採用挑戰者一方的說法。
- **主 agent 判斷**：E 的意見成立。C 確認的是「沈伯洋這樣說」（ATTRIBUTED），不代表遊戲可以把對方說法定性為謠言。建議改寫成兩方並列，並寫入 C12 的正式懲戒（見審查表 R4）。
- **需要你決定**：這題牽涉候選人家人的生意，是否保留在遊戲裡（見審查表 R4 的選項）。

## D3｜颱風天股市：遊戲句錯在哪裡（C19、C21）

- **B**：沈伯洋沒有主張由市長決定開盤；「搞錯中央地方權責」是國民黨方面的批評。遊戲把「股市歸中央管」寫成對手的批評，這一點對。
- **D**：證交所規則是「台北市長宣布停班，集中市場就休市」，所以遊戲句「股市……不是市長能決定的」方向錯一半：市長的停班決定實際上就決定了股市開不開；市長不能決定的是改變這條連動規則。
- **E**：同意 D；另外指出「記者問你股市」沒有出處，他是被問颱風假時主動提到。
- **主 agent 判斷**：三者互補。遊戲句要改兩處：拿掉「不是市長能決定的」，改寫成規則的實際樣子；把情境改成「被問颱風假時提到股市」。對手的批評照樣保留，並歸屬給批評者。

## D4｜「戰士沒有選擇戰場的權利」（C32）

- **C**：兩家以上媒體一致，建議 VERIFIED。
- **E**：同一場專訪有兩種措辭（「沒有選擇戰場的權利」與「很難且不容易選擇自己的戰場」）；遊戲漏掉本人隔天的澄清（那句話指無法選擇對岸是否通緝），寫成單純改口有偏頗風險。
- **主 agent 判斷**：引句可以用（鏡報、三立都記下「沒有選擇戰場的權利」），但情境要補上本人的澄清。

## D5｜F07「事實查核還了你清白」（C41）

- **B**：查核報告的結論是「並非沈伯洋所述」，傳言被用來質疑他編故事，所以「還了你清白」大致說得通。
- **主 agent（遊戲邏輯 QA）**：報告只澄清「這段故事不是他說的」，沒有替其他事情背書，標題說得太滿。
- **建議**：採較保守的寫法「查核報告出爐：那不是你說的」。這是語氣問題，不是事實錯誤，請你決定。

## D6｜R7 的因果順序（C22、C23）

- **D**：行政院的專案保護是因應「多起跨境鎮壓事件」，報導沒有說是因為這位藝人。
- **C、E**：國台辦 10-14 才回應，而且沒有點名。
- **主 agent 判斷**：遊戲把「藝人被批 → 行政院保護」寫成前後因果，要改成「同一個月」的並列，不暗示因果。
