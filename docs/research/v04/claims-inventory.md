# V0.4 第一輪：命題清單（Phase 0）

> 從 `web/src/content/special-capital.json`（commit `c00ca14`）抽出、涉及真實人物或真實事件的最小命題。
> 「遊戲句」是遊戲裡實際出現的文字；研究要回答的是：這句話在真實世界有沒有根據、根據在哪裡、精確程度到哪裡。
> 狀態一律從 UNVERIFIED 開始；v0.3 曾以工具開啟過的來源，只代表「有人讀過摘要」，不代表已查證。

## 狀態定義（依規格書 V0.4 第 7.2 節）

| 狀態 | 意思 |
|---|---|
| VERIFIED | 這個明確命題受可靠原始資料支持（本輪由 agent 標示時，一律只能標「建議 VERIFIED，待人工覆核」） |
| ATTRIBUTED | 可以確認有人這樣說，但內容未必為真 |
| DISPUTED | 有具體相反證據或不同解釋 |
| UNVERIFIED | 來源不足 |
| FALSE | 有明確反證 |
| SIMULATED | 完全虛構的遊戲情節 |
